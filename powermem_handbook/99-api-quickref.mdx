## 1. Python SDK 速查

来源: `src/powermem/core/memory.py` (同步) + `async_memory.py` (异步)

### 1.1 创建

```python
from powermem import create_memory, Memory, AsyncMemory

# 最简 (从 .env 自动配置)
memory = create_memory()                  # sync
amemory = AsyncMemory()                   # async

# 显式配置
from powermem import auto_config
memory = create_memory(config=auto_config())

# 传 dict
memory = create_memory(config={
    "llm": {"provider": "qwen", "config": {"api_key": "...", "model": "qwen-plus"}},
    "embedder": {"provider": "openai", "config": {"api_key": "..."}},
    "vector_store": {"provider": "oceanbase", "config": {"host": "...", "port": 2881, ...}},
})
```

### 1.2 核心 CRUD

| 方法 | 签名 | 返回 |
|------|------|------|
| `add(messages, ...)` | `messages: str \| dict \| list[dict], user_id=None, agent_id=None, run_id=None, metadata=None, filters=None, scope=None, memory_type=None, prompt=None, infer=True` | `Dict` 含 `results` + 可选 `relations` |
| `search(query, ...)` | `query: str, user_id=None, agent_id=None, run_id=None, filters=None, limit=30, threshold=None, retrieval_mode="auto", fusion="rrf", vector_weight=None, fts_weight=None, rrf_k=60, candidate_limit=None, include_explanation=False` | `Dict` 含 `results` + `relations` |
| `get(memory_id, user_id=None, agent_id=None)` | 拿一条 | `Dict` 或 `None` |
| `update(memory_id, content, user_id=None, agent_id=None, metadata=None)` | 改 content / metadata | `Dict` |
| `delete(memory_id, user_id=None, agent_id=None)` | 删一条 | `bool` |
| `delete_all(user_id=None, agent_id=None, run_id=None)` | 按 scope 删 | `int` (删除条数) |
| `get_all(user_id=None, agent_id=None, run_id=None, limit=100, offset=0, filters=None, sort_by=None, order="desc")` | 列出 | `List[Dict]` |
| `reset()` | 删库重建 | `None` |

### 1.3 Skill 管理

| 方法 | 签名 | 返回 |
|------|------|------|
| `distill_skills(messages, today=None)` | 从对话抽 skill | `List[Dict]` |
| `add_skill(title, description, tags=None, procedure=None, user_id=None, agent_id=None, skip_review=False, title_embedding=None, description_embedding=None)` | 写入一条 (带去重) | `Dict` 含 `action: created\|merged\|blocked` |
| `merge_skills(existing, new)` | 决策合并 | `Dict` 含 `action: merge\|skip` |
| `search_skills(query, limit=10, user_id=None, agent_id=None)` | 4 路检索 | `List[Dict]` |

### 1.4 异步版

所有上述方法在 `AsyncMemory` 都有异步版本 (`async def`), 签名相同 (除返回 awaitable)。例:

```python
await amemory.add(messages, user_id="alice")
results = await amemory.search("...", limit=5)
```

### 1.5 配置与诊断

```python
memory.config              # 当前生效的 config dict
memory.llm                 # LLM 实例 (e.g. QwenLLM)
memory.embedder            # Embedder 实例
memory.vector_store        # StorageAdapter → OceanBase 等
memory.skill_manager       # SkillManager (仅 OceanBase)
memory.telemetry           # TelemetryManager (opt-in)
memory.audit               # AuditLogger
```

## 2. HTTP API 速查

来源: `src/server/api/v1/` (`onBrokenLinks: 'throw'`)

服务端口默认 `8848` (`.env` 的 `POWERMEM_SERVER_PORT`), 路径前缀 `/api/v1`。

### 2.1 Memory 路由 (memories.py)

| Method | Path | 用途 |
|--------|------|------|
| POST | `/api/v1/memories` | 创建一条 (`infer=True` 默认走 LLM 抽取) |
| POST | `/api/v1/memories/batch` | 批量创建 |
| GET | `/api/v1/memories` | 列出 (filters, sort_by, order, time_range) |
| GET | `/api/v1/memories/stats` | 用户/agent 统计 |
| GET | `/api/v1/memories/sessions` | coding-agent session 列表 |
| GET | `/api/v1/memories/session-stats` | session 级统计 |
| GET | `/api/v1/memories/timeline` | 时间线 |
| GET | `/api/v1/memories/quality` | 质量分析 |
| GET | `/api/v1/memories/users` | 唯一 user_id 列表 |
| GET | `/api/v1/memories/export` | 导出 (JSON / CSV) |
| GET | `/api/v1/memories/{memory_id}` | 单条 |
| PUT | `/api/v1/memories/batch` | 批量更新 |
| PUT | `/api/v1/memories/{memory_id}` | 更新一条 |
| DELETE | `/api/v1/memories/batch` | 批量删除 |
| DELETE | `/api/v1/memories/{memory_id}` | 删除一条 |
| POST | `/api/v1/memories/import` | 导入 |

### 2.2 Search 路由 (search.py)

| Method | Path | 用途 |
|--------|------|------|
| GET | `/api/v1/memories/search` | GET 形式 (filter 都在 query string) |
| POST | `/api/v1/memories/search` | POST 形式 (body 传 filter, 推荐) |

Query/Body 字段: `query`, `user_id`, `agent_id`, `run_id`, `filters` (JSON), `limit`, `threshold`, `retrieval_mode`, `fusion`, `rrf_k`, `vector_weight`, `fts_weight`。

### 2.3 Observations 路由 (observations.py)

| Method | Path | 用途 |
|--------|------|------|
| POST | `/api/v1/observations` | 摄入 coding-agent observation (单条) |
| POST | `/api/v1/observations/batch` | 批量 (支持逐项 partial 失败) |

### 2.4 Users 路由 (users.py)

| Method | Path | 用途 |
|--------|------|------|
| GET | `/api/v1/users/{user_id}/profile` | 取画像 |
| POST | `/api/v1/users/{user_id}/profile` | 创建/覆盖画像 |
| PUT | `/api/v1/users/{user_id}/memories/{memory_id}` | 改用户某条记忆 |
| GET | `/api/v1/users/{user_id}/memories` | 列用户记忆 |
| DELETE | `/api/v1/users/{user_id}/profile` | 删画像 |
| DELETE | `/api/v1/users/{user_id}/memories` | 删用户所有记忆 |
| GET | `/api/v1/users/profiles` | 列所有画像 (支持主题过滤) |

### 2.5 Agents 路由 (agents.py)

| Method | Path | 用途 |
|--------|------|------|
| GET | `/api/v1/agents/{agent_id}/memories` | 列 agent 记忆 |
| POST | `/api/v1/agents/{agent_id}/memories` | 创建 agent 记忆 |
| POST | `/api/v1/agents/{agent_id}/memories/share` | 跨 agent 共享 |
| GET | `/api/v1/agents/{agent_id}/memories/share` | 列共享给该 agent 的记忆 |

### 2.6 System 路由 (system.py)

| Method | Path | 用途 |
|--------|------|------|
| GET | `/api/v1/system/health` | 健康检查 |
| GET | `/api/v1/system/status` | 服务状态 (version, storage_type, llm_provider, capabilities) |
| GET | `/api/v1/system/metrics` | Prometheus 指标 |
| DELETE | `/api/v1/system/delete-all-memories` | 管理员 wipe-all (gated) |

### 2.7 MCP 端点

| Path | 用途 |
|------|------|
| `/mcp` | FastMCP streamable-HTTP ASGI app, 13 tools (详见下节) |

### 2.8 Dashboard

| Path | 用途 |
|------|------|
| `/dashboard/` | React SPA (Memories / Sessions / User Profile / Settings) |

### 2.9 通用请求示例

```bash
# 创建记忆
curl -X POST http://localhost:8848/api/v1/memories \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"messages": "Alice likes PostgreSQL", "user_id": "alice"}'

# 搜索
curl -X POST http://localhost:8848/api/v1/memories/search \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"query": "数据库偏好", "user_id": "alice", "limit": 5}'

# 列出
curl "http://localhost:8848/api/v1/memories?user_id=alice&limit=10" \
  -H "X-API-Key: your-key"
```

### 2.10 错误格式

```json
{
  "error": {
    "code": "MEMORY_NOT_FOUND",
    "message": "Memory 123 not found",
    "details": {}
  },
  "timestamp": "2026-08-08T10:30:00Z"
}
```

常用错误码:

| Code | HTTP | 含义 |
|------|------|------|
| `INVALID_REQUEST` | 400 | 参数错误 |
| `UNAUTHORIZED` | 401 | API Key 缺失/错误 |
| `FORBIDDEN` | 403 | 无权限 |
| `NOT_FOUND` | 404 | 路径不存在 |
| `MEMORY_NOT_FOUND` | 404 | 记忆 ID 不存在 |
| `RATE_LIMIT_EXCEEDED` | 429 | 限流 |
| `STORAGE_ERROR` | 500 | 后端失败 |
| `LLM_ERROR` | 500 | LLM 调用失败 |
| `INTERNAL_ERROR` | 500 | 兜底 |

## 4. CLI 主命令速查

入口: `pmem` / `powermem-cli`

### 4.1 memory 子命令

```bash
pmem memory add "Alice likes PostgreSQL" \
  --user-id alice --infer

pmem memory search "数据库偏好" \
  --user-id alice --limit 5

pmem memory get 123 --user-id alice

pmem memory update 123 "Alice prefers Postgres" --user-id alice

pmem memory delete 123 --user-id alice --yes

pmem memory list --user-id alice --limit 10 \
  --sort-by created_at --order desc

pmem memory delete-all --user-id alice --confirm

pmem memory export --output alice.json --user-id alice
pmem memory import alice.json

pmem memory quality --user-id alice
pmem memory optimize
```

### 4.2 profile 子命令

```bash
pmem profile get alice
pmem profile list --main-topic preferences
pmem profile delete alice --yes
```

### 4.3 config 子命令

```bash
pmem config show
pmem config validate
pmem config test           # 测试 LLM/embedder/storage 连通性
pmem config init           # 交互式向导生成 .env
```

### 4.4 manage 子命令


## 5. 错误码对照 (Python SDK)

`Memory.add()` / `search()` 等方法可能抛:

| 异常 | 触发条件 |
|------|---------|
| `ValueError` | 参数错误 (e.g. messages=None, retrieval_mode 非法) |
| `RuntimeError("SkillStore not enabled")` | 主存储不是 OceanBase 时调 add_skill |
| `httpx.HTTPStatusError` | HTTP 后端 fallback 时上游返回 4xx/5xx |
| `ImportError` | 选用的 provider 包没装 (e.g. 没装 `anthropic` 用 anthropic) |
| `pydantic.ValidationError` | config 字段类型错误 |

## 7. 故障排查速查

| 现象 | 检查 |
|------|------|
| `Unsupported LLM provider` | 漏 import 了 config? 调 `BaseLLMConfig.get_provider_class_path("xxx")` 验证 |
| `LLM is disabled; falling back to simple add` | `LLM_PROVIDER=noop` 或 LLM 没装好 |
| 搜索结果空 | 后端不支持 hybrid? 改 `retrieval_mode="vector"` 或检查 embedding_dims |
| `SkillStore not enabled` | 主存储不是 OceanBase, 或 `SKILL_STORE_ENABLED=false` |
| HTTP 401 | `X-API-Key` 头缺失或错; 检查 `AUTH_ENABLED` |
| HTTP 429 | 触发限流; 调高 `RATE_LIMIT_PER_MINUTE` |
| `error_code=MEMORY_NOT_FOUND` | 用了 string ID 而非 int (MCP 场景常见) |
| `add_memory` 返回 `{"results": []}` | fact 抽取返回空, LLM 失败; 改 `infer=false` 临时绕过 |
| Source store 不可用 | 仅 OceanBase 模式支持; 关闭 `SOURCE_STORE_ENABLED` |
