# Mem0 Handbook — 三视角中文手册

> **本手册的目标**: 让不同角色的读者都能在 1-2 小时内形成对 mem0 的体系化认知。
> **形态**: 独立目录 `handbook/`,与官方 `docs/`(Mintlify 站点)互补——本文侧重"为什么 / 如何组合 / 怎么造",官方文档侧重"参数表 / API Reference"。
> **约定**: 中文叙述,英文技术术语括注(如:向量存储 / Vector Store)。所有 Mermaid 代码块在 GitHub / Mintlify / VSCode 中可直接渲染。

## 约定与术语

- **代码块标识**: ```` ```python ```` / ```` ```typescript ```` / ```` ```bash ````;Mermaid 用 ```` ```mermaid ````
- **文件引用**: `路径:行号` 形式,如 `mem0/memory/main.py:755`,在 IDE / GitHub 中点击可直接跳转
- **API 标注**: Python 类名用 `PascalCase`(如 `Memory`),TypeScript 类名同样;函数用 `snake_case` 或 `camelCase` 按语言保留
- **Mermaid 渲染**: GitHub / Mintlify / VSCode Markdown Preview / Mermaid Live Editor 均可渲染
