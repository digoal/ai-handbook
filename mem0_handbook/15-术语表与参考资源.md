## 异常类型速查

`mem0/exceptions.py` 定义 8 种异常,均继承 `MemoryError`:

| 异常 | `error_code` | 触发场景 | 修复建议 |
|---|---|---|---|
| `Mem0ValidationError` | `VALIDATION_003` | 输入 messages 格式错 | 转为 str / dict / list[dict] |
| `Mem0ValidationError` | `VALIDATION_001` | user_id 缺失 | 至少传一个 user_id / agent_id / run_id |
| `LLMError` | `LLM_001` | LLM 调用失败 | 检查 API key、模型可用性、网络 |
| `LLMError` | `LLM_002` | LLM 返回非 JSON | 改用支持 `response_format=json_object` 的模型 |
| `EmbeddingError` | `EMB_001` | embed 调用失败 | 检查 Embedder 配置 |
| `EmbeddingError` | `EMB_002` | 维度不匹配 | 保持 Embedder 一致,或重建 collection |
| `VectorStoreError` | `VS_001` | 连接失败 | 检查 host / port / 凭据 |
| `VectorStoreError` | `VS_002` | collection 不存在 | 首次 add() 会自动创建 |
| `DatabaseError` | `DB_001` | SQLite 写失败 | 检查 `history_db_path` 写权限 |
| `RateLimitError` | `RL_001` | LLM 限流 | 降低 QPS、升级套餐、加 retry |
| `RateLimitError` | `RL_002` | Embedder 限流 | 同上 |
| `MemoryQuotaExceededError` | `QUOTA_001` | Hosted 配额满 | 升级套餐或迁移到 OSS |
| `MemoryNotFoundError` | `NF_001` | get/update/delete 不存在的 id | 检查 UUID 复制正确 |

每种异常都有 `.message`、`.error_code`、`.details`、`.suggestion`、`.debug_info` 5 个字段:

```python
try:
    memory.add(..., user_id="alice")
except Mem0ValidationError as e:
    print(e.error_code, e.message, e.suggestion)
```

```python

    "llm": {"provider": "openai", "config": {"model": "gpt-4o-mini"}},
    "embedder": {"provider": "openai", "config": {"model": "text-embedding-3-small"}},
    "vector_store": {"provider": "qdrant", "config": {"path": "~/mem0/default"}},
    "history_db_path": "./memory_history.db",
}
```

### TypeScript `new Memory()` 零配置(`config/defaults.ts`)

```typescript
{
    llm: { provider: "openai", config: { model: "gpt-5-mini" } },
    embedder: { provider: "openai", config: { model: "text-embedding-3-small" } },
    vectorStore: { provider: "memory", config: { collectionName: "memories", dimension: 1536 } },

```
