# 如何使用本手册

> **版本基线**:Claude Code 2.1.214 · macOS 15.7.7 · 核验 2026-07-20

本章不教某个 Claude Code 功能，而是先说明怎样判断一条教程内容是否适用于你的版本。完成本章后，你应该能区分“本机实测”“官方核对”和“尚未验证”。

---

## 学习目标

- 理解滚动基线，而不是把某个版本误称为永远的最新版。
- 根据事实 ID 找到来源、版本、日期和适用边界。
- 在本机版本不同于手册时，知道何时继续、何时停下来复核。
- 为后续课程准备一个与重要项目隔离的练习目录。

## 场景示范：准备开始下一章，先核对本机版本

你准备开始 [01 安装与健康检查](../01-installation-and-health/README.md) 之前，想快速确认本机 Claude Code 与 macOS 仍在手册基线内，而不是版本漂移导致后续章节步骤不兼容。

### 实操

- 在 Terminal 运行 `claude --version` 与 `sw_vers`，把输出和当前基线表对照。
- 如果 Claude Code 版本与手册不同，按「## 先检查你的版本」走三步：从事实 ID 回溯来源、查官方文档、查官方 changelog。
- 如果 macOS 版本不同，先看章节是否声明了最低要求，不满足就先停下。

### 验证

- 输出的版本号与基线表完全一致，可以直接进入下一章。
- 若不一致，能识别出漂移来源（升级、安装渠道变化、订阅变化），并据此决定继续、复核还是停止。

## 先检查你的版本

在 Terminal 中运行：

```bash
claude --version
sw_vers
```

如果 Claude Code 版本与本手册不同：

1. 不要先假设旧命令仍兼容。
2. 打开章节末尾列出的事实 ID。
3. 从 [官方文档索引](https://code.claude.com/docs/llms.txt)进入对应功能页。
4. 查看 [官方 changelog](https://code.claude.com/docs/en/changelog)中两个版本之间的变化。
5. 无法确认时，停止复制该步骤；不要用猜测补齐参数或配置字段。

## 理解证据等级

### 已实测

表示在记录的 macOS 和 Claude Code 版本上实际观察过结果。例如，本手册保存了 `claude --version` 和 `claude --help` 的无敏感信息输出。

“已实测”仍然有版本边界。它不能证明其他版本、其他账户或其他平台行为完全相同。

### 官方核对

表示官方文档或官方 changelog 明确说明，但本手册没有执行该操作。例如，我们不会为了验证安装章节而重装 Claude Code，也不会为了验证认证章节而清除现有登录状态。

### 条件性

表示结论受订阅、认证方式、安装渠道、feature gate 或组织策略影响。课程必须把条件写在结论旁边。

### 待验证

表示证据不足。待验证内容只能出现在章节骨架的“待核验问题”中，不能作为操作步骤。

完整规则见 [VERIFICATION.md](../VERIFICATION.md)。

## 准备练习目录

后续课程会修改文件。先创建一个不含真实业务代码、凭证或私人资料的目录：

```bash
mkdir -p ~/claude-code-handbook-lab
cd ~/claude-code-handbook-lab
```

不要直接在 home 目录启动课程练习，也不要把生产仓库作为第一次实验对象。

## 每章学习流程

1. **检查前置条件**：确认本机版本和章节基线。
2. **阅读边界**：先看本章不覆盖什么。
3. **运行最小示例**：一次只改变一个因素。
4. **观察结果**：使用 `git diff`、测试或明确输出验证。
5. **检查事实 ID**：确认命令和行为来自本机证据或官方资料。
6. **决定是否保留**：练习结束后明确保留、回退或删除实验内容。

## 常见误区

### 官方页面能访问，就代表教程事实正确

不对。链接检查只能证明 URL 可访问，不能证明页面仍支持教程中的具体句子。必须阅读页面内容并记录核验日期。

### help 中出现一个 flag，就代表所有账户都能使用

不对。help 可以证明当前二进制接受该参数，但不能消除订阅、认证、feature gate 或组织策略条件。

### 当前命令运行成功，就能省略版本号

不对。CLI、默认值和交互界面会变化。易变事实必须保留版本边界。

### 现有课程写过，就可以直接复制

不对。现有课程只能提供线索。进入本手册正文前仍要重新核验。
