# §20 本地开发环境搭建

> 🧑‍💻 开发者
>
> **一句话定位**:从零开始,搭建可运行 v4.3.5 PostgreSQL Community Edition 的本地开发环境,涵盖 Python / PostgreSQL / 扩展 / 离线 wheel。

---

## 1. 环境清单

| 组件 | 版本 | 用途 |
|---|---|---|
| **Python** | 3.14+ | 运行时 |
| **PostgreSQL** | 18.3+ | 数据库 |
| **psycopg2** | ≥ 2.9 | Python 驱动 |
| **pgvector** | 最新 | 向量嵌入 |
| **pg_trgm** | 系统自带 | 模糊匹配 |
| **pgcrypto** | 系统自带 | 列加密 |
| **pg_cron** | 最新 | 定时任务 |
| **Apache AGE** | 1.7+ | 属性图投影 |
| **Node.js** | (可选) | 仅前端开发需要 |
| **OpenSSL** | 3.x | cryptography wheel 构建 |

> 📌 **不需要 Node.js 运行平台**;`web/dist/` 已预构建,FastAPI 直接挂载。

## 2. PostgreSQL 准备

### 2.1 安装扩展

```sql
-- 连接到目标数据库后
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS pg_cron;
CREATE EXTENSION IF NOT EXISTS age;

-- AGE 需要 schema
CREATE SCHEMA IF NOT EXISTS ag_catalog;
```

### 2.2 Schema Owner

来源:[`SKILL.md:57-62`](../SKILL.md)

平台部署需要 Schema Owner 用户,具备:

```sql
-- 必要权限
CREATE ROLE ai_agent_runtime WITH LOGIN CREATEROLE ADMIN OPTION;
GRANT CONNECT ON DATABASE your_db TO ai_agent_runtime;
GRANT CREATE ON DATABASE your_db TO ai_agent_runtime;
-- AGE 权限
GRANT USAGE ON SCHEMA ag_catalog TO ai_agent_runtime;
```

> ⚠️ **Schema Owner ≠ 业务 Agent**。业务 Agent 使用独立 LOGIN 角色 + RLS,永远不能 fallback 到 Schema Owner。

## 3. Python 环境

### 3.1 在线安装

```bash
cd /path/to/package
pip install -r requirements.txt
```

`requirements.txt` 内容(摘自本仓库):

```text
psycopg2-binary>=2.9
cryptography==49.0.0
argon2-cffi==25.1.0
argon2-cffi-bindings
annotated-doc==0.0.4
fastapi==0.120.4
uvicorn[standard]
python-multipart
pyjwt
requests
pydantic
# ... (详见 requirements.txt)
```

### 3.2 离线安装

来源:[`docs/python-runtime.md`](../python-runtime.md)、[`scripts/python_runtime.sh`](../../scripts/python_runtime.sh)

```bash
# 加载运行时辅助函数
source scripts/python_runtime.sh

# 解析 Python 3.14+ 解释器
export PYTHON_BIN="$(cx_resolve_python)"

# 准备虚拟环境
cx_prepare_python_environment "$PYTHON_BIN"

# 安装 vendor/ 下的所有 wheel
./scripts/install_offline.sh
```

### 3.3 验证依赖

```bash
"$PYTHON_BIN" scripts/verify_deps.py
```

来源:[`scripts/verify_deps.py`](../../scripts/verify_deps.py)

`verify_deps.py` 会:
- 检查每个 wheel 文件名与平台兼容
- 解析 `Requires-Dist` 元数据,递归依赖验证
- 检查 glibc floor(默认 2.28 for RHEL 8)
- 失败 fail-closed,exit 非 0

## 4. 配置

### 4.1 首次运行向导

```bash
./start_web_server.sh start
```

首次运行会检测 `config.json` 中的 `<PLACEHOLDER>` 标记,如果存在则启动 `config_wizard.sh` 引导填写。

来源:[`scripts/config_wizard.sh`](../../scripts/config_wizard.sh)、[`scripts/start_web_server.sh`](../../scripts/start_web_server.sh)

### 4.2 手动配置

```bash
cp config.example.json config.json
# 编辑 config.json,替换所有 <PLACEHOLDER>
vim config.json
```

### 4.3 自动加密

服务器首次启动会**自动加密**敏感字段:

| 字段 | 加密方式 |
|---|---|
| `database.password` | AES-256-GCM + PBKDF2-HMAC-SHA512 |
| `security.session_secret` | 同上 |
| `llm.api_key` | 同上 |
| `model_routing.*.api_key` | 同上 |

> 加密后,`config.json` 是 owner-only (`0600`),明文**不再**保留。

来源:[`lib/connection_crypto.py`](../../scripts/lib/connection_crypto.py)、[`scripts/tools/encrypt_config.py`](../../scripts/tools/encrypt_config.py)

## 5. 数据库 Schema 部署

### 5.1 顺序应用

```bash
# 1. 核心 schema
psql -U ai_agent_runtime -d your_db -f scripts/deploy/1_schema.sql

# 2. API 层
psql -U ai_agent_runtime -d your_db -f scripts/deploy/2_api.sql

# 3. 调度任务
psql -U ai_agent_runtime -d your_db -f scripts/deploy/3_jobs.sql

# 4. Harness 模板
psql -U ai_agent_runtime -d your_db -f scripts/deploy/4_harness_templates.sql

# 5. v4.0.1 baseline
psql -U ai_agent_runtime -d your_db -f scripts/deploy/7_v4_0_1_migration.sql

# 6. v4.1.0 注册(Community)
psql -U ai_agent_runtime -d your_db -f scripts/deploy/8_v4_1_0_registration.sql

# 7. v4.2.0 graph (Community 9-12)
for f in scripts/deploy/9_v4_2_0_graph_engineering.sql \
         scripts/deploy/10_v4_2_0_graph_runtime.sql \
         scripts/deploy/11_v4_2_0_graph_control.sql \
         scripts/deploy/12_v4_2_0_graph_edge_scope.sql; do
  psql -U ai_agent_runtime -d your_db -f "$f"
done

# 8. v4.2.0 graph triggers + executor
psql -U ai_agent_runtime -d your_db -f scripts/deploy/14_v4_2_0_graph_triggers.sql
psql -U ai_agent_runtime -d your_db -f scripts/deploy/15_v4_2_1_executor_registry.sql

# 9. v4.3.0-3.5 migrations (16-31,skipping Enterprise-only 29/30)
for f in scripts/deploy/16_v4_3_0_identity_channels.sql \
         scripts/deploy/17_v4_3_0_governance_lifecycle.sql \
         scripts/deploy/18_v4_3_0_security_lifecycle.sql \
         scripts/deploy/19_v4_3_1_organization_governance.sql \
         scripts/deploy/20_v4_3_1_human_display_name.sql \
         scripts/deploy/21_v4_3_1_entry_access.sql \
         scripts/deploy/22_v4_3_1_identity_organization_alignment.sql; do
  psql -U ai_agent_runtime -d your_db -f "$f"
done

# 10. v4.3.2 memory lifecycle
for f in scripts/deploy/23_v4_3_2_memory_lifecycle.sql \
         scripts/deploy/24_v4_3_2_memory_digest_alignment.sql \
         scripts/deploy/25_v4_3_2_disable_legacy_memory_fusion.sql \
         scripts/deploy/26_v4_3_2_snapshot_subject_fencing.sql \
         scripts/deploy/27_v4_3_2_memory_governance_completion.sql; do
  psql -U ai_agent_runtime -d your_db -f "$f"
done

# 11. v4.3.3 graph assurance
psql -U ai_agent_runtime -d your_db -f scripts/deploy/28_v4_3_3_graph_assurance.sql

# 12. v4.3.5 platform capabilities
psql -U ai_agent_runtime -d your_db -f scripts/deploy/31_v4_3_5_platform_capabilities.sql
```

### 5.2 使用 migration_runner 自动应用

```bash
"$PYTHON_BIN" scripts/migration_runner.py --version 4.3.5
```

`migration_runner.py` 会:
- 检查目标版本依赖的表/列是否已存在
- 跳过已应用的部分(幂等)
- 写入 `ai_schema_migrations` 账本
- 失败回滚到上版本

来源:[`scripts/migration_runner.py`](../../scripts/migration_runner.py)

## 6. 启动服务

### 6.1 一键启动

```bash
./start_web_server.sh start
```

子命令:`start` / `stop` / `restart` / `status` / `config` / `log`

### 6.2 手动启动

```bash
source scripts/python_runtime.sh
export PYTHON_BIN="$(cx_resolve_python)"
cx_prepare_python_environment "$PYTHON_BIN"

PYTHONPATH=scripts "$PYTHON_BIN" -m uvicorn web_app:app \
  --host 0.0.0.0 \
  --port 18080
```

### 6.3 健康检查

```bash
curl http://localhost:18080/api/health
# {"status": "ok", "version": "4.3.5", ...}
```

## 7. 常见环境问题

| 问题 | 原因 | 修复 |
|---|---|---|
| `cryptography` 安装失败 | glibc 不匹配 | 重新构建 `manylinux_2_28` wheel |
| pgvector 报错 | 扩展未安装 | `CREATE EXTENSION vector` |
| RLS 过滤不到行 | 没设 `app.current_agent_id` | 检查 `lib/connection.py` |
| 端口 18080 占用 | 已有实例 | 修改 `--port` 或停旧实例 |
| `agent_id not found` | 凭据未注入 | 检查 `config.json` 与 auto-encrypt |
